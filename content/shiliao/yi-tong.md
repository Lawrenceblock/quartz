# 小说与史料的异同

| 项 | 小说 | 史料 | 说明 |
| --- | --- | --- | --- |
| 时代 | 崇祯十一年 | 戊寅虏变前夜 | 吻合 |
| 王府 | 「给王府推盐推粮」 | **宁阳王府**（朱由椅），考古已发掘 | 吻合 |
| 季木先生 | 王象春，避祸山中 | 王象春，卒于崇祯五年 | 小说留白 |
| 亭名 | 正文作「见山亭」 | 王象春所筑为「**问山亭**」 | **已裁定：作「问山亭」**（作者 2026-10-23） |
| 桥名 | 「捍石桥」 | 崇祯《历城县志》作「旱石桥」 | **待核** |
| 陈金二教长 | 陈家世袭掌教、金叔 | **《历城县志·忠烈》原文** | 吻合 |
| 陈氏世袭掌教 | 陈英、陈礼、陈玺、陈思 | 见诸碑记 | 吻合 |
| 刘文达 | 刘瓒之后，青州府学生员 | 刘瓒实有其人 | 小说家言 |
| 陈二把式、陈五爷、金叔 | 主要人物 | 无考 | 虚构 |

> **已裁定一项**：**亭名作「问山亭」**（作者 2026-10-23 裁定）。王象春所筑本作「问山亭」，其诗集即名《问山亭集》《问山亭遗诗》。**正文《长春观（二）》三处作「见山亭」，待作者改。**
>
> **待核一项**：《城顶（二）》《地方》作「**捍石桥**」，而崇祯十三年《历城县志》作「**旱石桥**」（俗作「杆石桥」）。或系小说有意改易，或系笔误，留待作者裁定。
