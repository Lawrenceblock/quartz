# 结构

现已刊出五组：

| 组 | 篇目 | 所写 |
| --- | --- | --- |
| 饮虎池 | （一）（二）（三） | 陈二把式一日之始：打水、煮糊糊、穿巷去城顶 |
| 城顶 | （一）（二） | 撞见刘秀才；军差过路，回肉铺求活 |
| 长春观 | （一）（二） | 刘秀才回溯：写状、识陈五爷、落第、结缘季木先生 |
| 雅集 | （一）（二）（三）（四） | 刘秀才赴白雪楼诗会：船上赴会；席上时局、与怀晋一照面；刘敕到、席上念《西门》；限题赋诗、怀晋问话、曲终人散 |
| 历城县 | （一）—（六） | 张书办夜归县衙：复命、翻检旧档、认出字迹；旧案始末；陈二报丧、回营要埋体；回营聚众入城领尸，县尊当堂断还；左堂召见，命往东关、回营两处安抚 |

五组各以地名立目，各篇以「一」「二」「三」标次。饮虎池写「生计」，城顶写「时局」，长春观写「来历」——三个方向，都从陈二把式这个人的一天里岔出去。

雅集一组另起，视角在刘秀才：自长春观门前的撞、赴湖上诗会，一路写去。

历城县一组，视角在张书办：诗会散后，自湖上回衙，向左堂复命，夜里翻出旧档，认出刘秀才的字迹。
