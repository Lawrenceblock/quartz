# 待办

- [ ] 城顶之后的去向：军差南行，兵马未至，下一步写什么
- [x] 上、下章导航（读者阅读体验）
- [ ] 篇末或可附简注，指涉史料出处
- [ ] 新增章节时，在 frontmatter 里补 `chapter` 序号（决定上/下章顺序）
- [ ] **宁阳王如何落笔**：旧作《宁阳王》走的是英雄叙事，本作需另寻写法。其人崇祯十一年「不知所踪」，十三年题「清真」匾，明亡后再无记载——史书留白处，恰是小说可为处
- [ ] 回兵守西关一段（陈金两教长、战死二百余人）如何入文：官修志书只给了一行
- [ ] 并渡口一线：回营南撤、朱家后人避居仲宫、宁海王墓同在南山——是否写成一条「撤出去」的线
- [ ] 太甲山：志书作「太甲陵，中宫东南」，今有摩崖造像。仲宫这一片山场，是否作为小说地理的一个坐标
- [ ] 祭田一节：朱家所恃是礼俗惯例而非明律，此中分寸如何写
- [ ] 诗会一场：刑名书办认字拉回陈家旧案。律例已备（「私开圈店」入例、累犯充军、老病牛须领判状），书办掌判状之权于制度有据。惟「回营是军屯地」尚待核
- [ ] 大户的「影子」：明代军屯被侵吞有实录可引（正统六年王骥奏、正统九年大宁都司、弘治榆林），回营具体情形待考
- [ ] 杨四知禁屠牛榜（万历十四年，《万历野获编》）如何用：书办引旧例，非当时新政
- [ ] 「拱宸门」须再考：西门本名泺源门，此称来源不明
